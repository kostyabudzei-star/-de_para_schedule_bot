# 🎓 Telegram-бот "Розклад занять"

Бот на **aiogram 3.x**, який показує студенту:
- що відбувається зараз (пара / перерва / очікування першої пари);
- розклад на сьогодні, завтра та весь тиждень;
- з урахуванням чергування тижнів (чисельник/знаменник).

## 📁 Файли проєкту

| Файл | Призначення |
|---|---|
| `bot.py` | Основний код бота (запускається) |
| `schedule_data.py` | Розклад занять + логіка чисельник/знаменник — **редагуй тут свій розклад** |
| `requirements.txt` | Список залежностей |
| `.env.example` | Приклад файлу з токеном (треба скопіювати в `.env`) |

## 1. Створення бота в @BotFather і отримання токена

1. Відкрий Telegram і знайди офіційного бота **@BotFather**.
2. Надішли команду `/start`, потім `/newbot`.
3. Введи назву бота (буде відображатись у чатах), наприклад: `Мій Розклад`.
4. Введи унікальний username бота, який обов'язково має закінчуватись на `bot`, наприклад: `my_schedule_helper_bot`.
5. BotFather надішле повідомлення з токеном виду:
   ```
   123456789:AAHk3jX9...................
   ```
   Скопіюй цей токен — він знадобиться далі.
6. Посилання на твого бота матиме вигляд:
   ```
   https://t.me/my_schedule_helper_bot
   ```
   (тобто `t.me/<username, який ти вказав>`).

**Порада:** одразу в BotFather можна встановити опис (`/setdescription`), картинку (`/setuserpic`) і список команд (`/setcommands`), наприклад:
```
now - Що зараз (пара/перерва)
today - Розклад на сьогодні
tomorrow - Розклад на завтра
week - Розклад на тиждень
```
(бот сам встановлює ці команди програмно при запуску, але можна продублювати і тут).

## 2. Встановлення залежностей та запуск локально

Потрібен встановлений **Python 3.10+**.

1. Розпакуй/скопіюй усі файли проєкту в одну папку.
2. Відкрий термінал у цій папці та створи віртуальне середовище (рекомендовано):
   ```bash
   python -m venv venv
   ```
   Активуй його:
   - Windows: `venv\Scripts\activate`
   - macOS/Linux: `source venv/bin/activate`
3. Встанови залежності:
   ```bash
   pip install -r requirements.txt
   ```
4. Створи файл `.env` на основі `.env.example`:
   ```bash
   cp .env.example .env      # macOS/Linux
   copy .env.example .env    # Windows
   ```
   Відкрий `.env` і встав свій реальний токен:
   ```
   BOT_TOKEN=123456789:AAHk3jX9...................
   ```
5. Відредагуй `schedule_data.py`:
   - заповни словник `SCHEDULE` своїми предметами, корпусами та аудиторіями;
   - за потреби зміни час пар у `PAIR_TIMES`;
   - зміни `WEEK_PARITY_REFERENCE` на дату понеділка, який у твоєму ВНЗ вважається **чисельником**.
6. Запусти бота:
   ```bash
   python bot.py
   ```
7. У Telegram відкрий свого бота за посиланням `t.me/<username>` і натисни `/start`.

## 3. Безкоштовний деплой, щоб бот працював 24/7

### Варіант А: Render.com (Background Worker)

1. Заведи проєкт у GitHub-репозиторії (завантаж туди `bot.py`, `schedule_data.py`, `requirements.txt`). **Файл `.env` в репозиторій не заливай** — токен буде додано окремо через налаштування Render.
2. Зареєструйся на [render.com](https://render.com) (можна через GitHub).
3. New → **Background Worker** → підключи свій GitHub-репозиторій.
4. Налаштування:
   - **Runtime:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `python bot.py`
5. У розділі **Environment** додай змінну:
   ```
   BOT_TOKEN = твій_реальний_токен
   ```
6. Натисни **Deploy**. Render збере проєкт і запустить бота — він працюватиме постійно (на безкоштовному плані Render може "засинати" воркер, якщо довго немає активності — тоді краще брати платний план або тримати активність через простий пінг-скрипт).

> Примітка: для Telegram-ботів у режимі polling підходить саме **Background Worker**, а не Web Service (Web Service вимагає відкритого HTTP-порту, чого тут не потрібно).

### Варіант Б: PythonAnywhere

1. Зареєструйся на [pythonanywhere.com](https://www.pythonanywhere.com) (безкоштовний план "Beginner").
2. Завантаж файли проєкту через вкладку **Files** (або клонуй через Git у вкладці **Consoles → Bash**, якщо доступно).
3. Відкрий **Bash-консоль** і встанови залежності:
   ```bash
   pip install --user -r requirements.txt
   ```
4. Створи `.env` файл прямо в PythonAnywhere зі своїм токеном (через редактор файлів або `nano .env`).
5. Postiйний процес (`python bot.py` у режимі polling) на безкоштовному плані PythonAnywhere **не підтримується напряму** (там немає "always-on tasks" на free-тарифі) — для цього варіанту знадобиться платний тариф "Hacker" з опцією **Always-on task**, у якій просто вказуєш команду:
   ```bash
   python3.10 /home/твій_логін/bot.py
   ```

### Варіант В (альтернатива): Railway.app / Fly.io

Обидва сервіси мають безкоштовні ліміти й підтримують деплой звичайного Python-скрипту в режимі "worker", аналогічно до Render — процес такий самий: підключення GitHub-репозиторію, встановлення `BOT_TOKEN` як змінної середовища, команда запуску `python bot.py`.

## ✏️ Як редагувати розклад

Весь розклад знаходиться у файлі `schedule_data.py` у словнику `SCHEDULE`. Кожен запис — одна пара:

```python
{"pair": 2, "subject": "Назва предмета", "type": "Лекція",
 "building": "Корпус 2", "room": "105", "week": "any"}
```

- `pair` — номер пари (час беруть із `PAIR_TIMES`);
- `week`:
  - `"any"` — пара щотижня;
  - `"odd"` — тільки на чисельник;
  - `"even"` — тільки на знаменник.

Якщо на одну й ту саму пару в один день припадають різні предмети для чисельника й знаменника — просто додай два записи з однаковим `pair`, але різним `week`.
